### 👨🏻‍💻 &nbsp;Sobre mí

👨‍💻 &nbsp;Soy estudiante de Ingeniería de Sistemas Computacionales con experiencia Fullstack; hoy mi foco está en el **Backend con Java y Spring Boot**.\
🧩 &nbsp;Me interesa construir sistemas que **no pierden ni duplican datos aunque algo falle**: microservicios que se comunican por **Kafka**, sagas orquestadas, patrón Outbox, consumidores idempotentes y reintentos con backoff.\
💡 &nbsp;También desarrollo con NodeJS / NestJS, Angular y React, sobre PostgreSQL, MySQL, SQL Server y MongoDB.\
🎨 &nbsp;Mis principales cualidades son la creatividad, la perseverancia y la dedicación.\
💼 &nbsp;En equipo aplico buenas prácticas: código probado, documentado y fácil de explicar.\
🚀 &nbsp;Aprendo de forma autónoma. Ahora mismo: **Go**, **Kotlin con Ktor** y operar Kafka en producción.\
📫 &nbsp;Abierto a oportunidades como **practicante o junior Backend**.

### 🧠 &nbsp;Lo que aplico en mis proyectos

- **Arquitectura:** microservicios con una base de datos por servicio y arquitectura hexagonal (puertos y adaptadores).
- **Mensajería y consistencia:** saga orquestada, Transactional Outbox, idempotencia (Idempotency-Key y consumidores idempotentes), reintentos con backoff y Dead Letter Topics.
- **Reactivo y concurrencia:** Spring WebFlux, R2DBC y virtual threads de Java 21.
- **Calidad:** pruebas con JUnit 5, `@EmbeddedKafka`, Jest y Vitest; CI con GitHub Actions; imágenes Docker multi-stage.
- **Seguridad:** autenticación con JWT en Spring Security, NestJS (Passport) y Go.
